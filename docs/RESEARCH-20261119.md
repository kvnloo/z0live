# Conversation flow: state of the art, 2026-11-19

Question: how do we get Dessa-level conversation (timing, backchannels, overlap, staying quiet) with Hermes-level
intelligence, whichever voice model is underneath? This brief adds to the existing record (#44 SOTA updates
10-23 .. 11-02, PR #33 `RESEARCH_TRACEABILITY.md`, PR #48 `DESSA-PHONE-NORTH-STAR.md`, PR #47 local Pareto
bench). Labels: **measured** = run by us; **reported** = from the source's abstract or text; **inferred** = our reading.

## Where z0live stood (11-02, #44)

- No downloadable small full-duplex model reproduces GPT-Live or Dessa on a phone. "Full-duplex media (AEC,
  barge, epochs) is engineering; full-duplex semantics is still research."
- Tiny streaming TTS (Phonon 31M, Pocket TTS) is real-time on phone CPUs; 0.6B TTS (Lure, Qwen3-TTS) is the
  naturalness ceiling but 2.5-6x slower than real time on the phone.
- S25 Ultra NPU prefills 5.5x faster than its CPU (Qwen3-0.6B 3109 vs 561 tok/s, measured 11-02).

## The target, measured today

Block published two-track recordings of its Dessa demos (one file per speaker). `voice-adapter/bench/dessa_timing.py`
re-implements the method of ai.thesatyajit.com/articles/dessa (energy talkspurts per track, floor-take offset =
start minus the other speaker's last end) on the 20 pairs we could download (71.7 min). **Measured:**

| | floor-takes | median gap | middle half | starts in overlap | waits > 1 s | backchannels/min |
|---|---|---|---|---|---|---|
| Dessa | 616 | **+0.31 s** | -0.04 .. +0.71 s | **26.5 %** | 14.9 % | **2.6** |
| the people talking to it | 584 | +0.41 s | 0.00 .. +0.68 s | 25.0 % | 10.8 % | 2.1 |

The article reports +0.24 s and 29.5 % over 19 calls that exclude the two GPT-Live demos; our set includes them.
Reference audio stays private under `~/.local/share/z0live/dessa-ref/` (analysis only, never redistributed).

## What the field learned since (papers read today)

**Hosted voices talk at every pause.** *People Making Conversation* (arXiv 2610.12802, Oct 8) placed six systems at
427 pauses and 482 turn ends from 176 real conversations: GPT Realtime, Gemini 3.1 Flash Live and Grok Voice
"respond at almost every pause whichever endpointer they use"; latency is ~1-4 s with silence endpointers and ~8 s
with semantic turn detection. Only the full-duplex models (PersonaPlex, Moshi) regularly stay silent and interrupt
within human reaction time, and hosted systems reply longer than the person (reported). This is the gap to Dessa in
one sentence: not speed, but **knowing when not to speak**, plus brevity.

**Humans start before the turn ends.** *TurnBench* (Sesame, 2608.25218): in smooth transfers listeners begin a median
**151 ms before** the current turn ends; no system matches that without excessive false positives; interruption false
positives concentrate in backchannel-dense conversation (reported). Consistent with Dessa's 26.5 % overlap starts.

**Learned end-of-turn alone is not enough; keep a hybrid controller.** *Voice-Light* (2609.20995): a learned completion
model had 12.5 % end-of-turn recall vs 95.6 % for a Silero timing policy, so the deployed system keeps acoustic onset
immediate, prepares replies privately and speculatively, makes playback reversible, speaks bridge audio while tools
run, and builds history only from audio the listener actually heard (reported).

**Split fast talking from slow thinking, and say something while thinking.**
- *SALMONN-duo* (2609.34247): an always-on fast full-duplex model (system 1) learns when to answer and when to delegate
  to a slow agent (system 2), stays responsive during backend work and folds results back in without tool traces
  (reported). This is z0live's architecture (voice + lanes + Hermes).
- *Spoken Language Models that Think Aloud* (2609.26488): a light think-aloud stream emits short task-grounded progress
  utterances while the reasoning stream works, cancelled when the answer is ready; less audible silence at equal
  accuracy (reported).
- *LTS-VoiceAgent* (2601.19952): a semantic trigger starts thinking on meaningful prefixes; a background Thinker keeps
  state while a foreground Speaker answers (reported).
- *DuplexPO* (2607.07148): when-to-speak can be learned as a separate policy (RL on human dialogue) without hurting
  what-to-say (reported). *DuplexSLA* (2605.20755) puts tool actions on the same 160 ms clock as speech.

**Measure distributions, not just latency.** *Conversational Distribution Score* (2609.31719): eight interpretable
rhythm/turn features compared with human reference distributions recover 5 of 6 listener system comparisons.
*TurnNat* (2607.01345): likelihood of the observed two-speaker activity under a turn-taking model, validated on
perturbation pairs (reported).

**More than one AI on a call.** *MultiPartyTurnBench* (2610.20172): learned systems reach 82.5-92.6 % end-of-turn recall
at 4.3-11.8 % false positives, but interruption (floor takeover) detection is weak (reported). *ModeratorLM*
(2606.13544): conditioning turn-taking on an assigned role improves precision > 40 % (reported). *Neural back-channel
generation and voice-line scheduling* (2611.24086, Nov 18): schedules two separately produced voice tracks into one
conversation, inserting pauses, overlap and backchannels (reported); the closest prior art to "recreate a Dessa call
with two voice models".

**Non-verbal sounds.** *Speech LLMs That Breathe* (2610.25942): 13 non-verbal vocalization types, NVV-aware GRPO
(reported). Lure-TTS 0.6B already takes inline `(laugh) (sigh) (hmm)` cues (#44).

**Models and runtimes new or updated since 11-02.** Sophon-Realtime v1.4.0 adds a 4B E2E full-duplex model; its 32B
Flash-4bit MLX build runs on a 36 GB Mac with ~1 s to speak (reported). Kyutai `moshika-rl-seamless` and
`personaplex-rl-seamless` (RL-tuned Moshi/PersonaPlex), MoshiRAG (asynchronous retrieval inside a full-duplex model).
PersonaPlex runs in vLLM-Omni's unified full-duplex framework. LFM3-Audio-2B has a LiteRT build. Pipecat smart-turn v3
(open semantic end-of-turn). ixi-sLM (2610.19382): a 1.2B call agent on a mobile NPU in 803 MiB at 94 % of a cloud
LLM's quality (reported).

## What this means for z0live (inferred, ranked)

1. **Score against Dessa, not against latency alone.** Freeze the Dessa replay as the hill-climb metric: feed the human
   side of each reference call into a z0live call and compare floor-take gap, overlap starts, waits > 1 s, backchannels
   per minute and reply length against the Dessa row above (a CDS-style distance), per engine.
2. **Own the when-to-speak decision where the engine lets us.** GPT-Live decides its own turns. Grok's Realtime API does
   not have to: with server VAD set not to create responses, z0live can choose when Grok speaks (smart-turn v3 locally,
   plus a short-reply policy). That makes Grok the first engine where Dessa-like silence is buildable.
3. **Fill thinking time with think-aloud, not silence.** A cheap lane emits one short, grounded progress line while
   Hermes works and is cancelled when the answer lands (the `tool-narrator` idea, now with a paper).
4. **Brevity is a lever.** Hosted voices reply longer than people; the persona and the lane prompt should cap spoken
   length, and the bench should measure reply duration.
5. **Two voices on one call: address by name.** Learned floor-takeover detection is the weakest part of multi-party
   turn-taking, so the first version routes by name and keeps one speaker at a time.
6. **Local full-duplex arms for the Studio bench:** Sophon-Realtime 4B E2E (MLX), PersonaPlex 7B (MLX via speech-swift),
   moshika-rl-seamless. They are the only open systems the evidence says can stay quiet and backchannel.
